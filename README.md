# Audio_Processing            
    
НС для генерации аудио.       
        
**Задача:**     
Обучить модель генерировать аудио в стиле Шопена.        
       
**Использованные технологии:**       
Keras, Pretty MIDI              
      
**Результаты**     
Из примеров произведений Шопена подготовлены данные и обучена модель для генерации продолжения произведения по некоторому началу.      
        
**Как запустить проект**       
Создайте блокнот в Google Colab     
Скопируйте код из main.ipynb      
Запустите выполнение кода
